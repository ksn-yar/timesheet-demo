## Задействуй агента backend-architect, который должен:
- прочитать docs/infra-vars.md и создать в папке app docker-compose.yaml по 1 варианту
- все образы должны лежать в папке app/docker в каждой своей подпапке
- для app сервиса дополнительно сделать:
  * установить PHP расширения Ctype, iconv, PCRE, Session, SimpleXML, Tokenizer, если они отсутствуют
  * установить Composer
  * пользователь www
  * установить xdebug
  * добавить возможность изменять php.ini (конфиг php) в контейнере, не заходя в него
- для nginx сервиса дополнительно сделать:
  * логи веб-сервера должны писаться в папку app/var/logNginx с ротацией по суткам
  * добавить возможность изменять nginx.conf (конфиг веб-сервера) в контейнере, не заходя в него
- для db сервиса дополнительно сделать:
  * монтировать хранение файлов в app/docker/data/db 
  * добавить возможность изменять конфиг postgres в контейнере, не заходя в него
- для всех docker сервисов применить:
  * префикс у наименования контейнера должен быть corpo-ts-
  * перезапуск только unless-stopped
  * не назначать порты по умолчанию, выбирать из диапозона 11000 - 12000
  * все environment параметры должны быть в файле .env в корне проекта
