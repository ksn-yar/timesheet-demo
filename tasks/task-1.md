# Задача на создание документации по проекту.
## Задействуй агента product-owner, который должен создать бизнес требования проекта со следующими инвариантами:
- документ с бизнес-требованиями должен создаться в docs/bt.md 
- стиль документа markdown
- проект называется "corpo-timesheet"
- цель и назначение проекта: локальная корпоративная система учета рабочего времени
- в папке docs есть скриншот диаграммы event storming (Timesheet.jpg) и его расшифровка EventStormingTranscript.md, обязательно к прочтению для понимания, какие бизнес-требования описывать
- на текущем этапе не предлагать инфраструктурные решения

## Задействуй агента business-analyst, который должен создать техническое задание проекта со следующими инвариантами:
- прочитай бизнес-требования docs/bt.md
- документ с техническим заданием должен создаться в docs/technical-specification.md
- стиль документа markdown
- на текущем этапе кодовой базы не существует
- на текущем этапе не предлагать инфраструктурные решения
