# Требования

## PHP

**Версия:** 8.4+

## Расширения PHP

| Расширение | Назначение |
|------------|------------|
| `ext-ctype` | Проверка типов символов (встроено в PHP 8.4) |
| `ext-iconv` | Преобразование кодировок (встроено в PHP 8.4) |
| `ext-intl` | Интернационализация и локализация |
| `ext-opcache` | Кэширование байт-кода для ускорения работы |
| `ext-pdo_pgsql` | Подключение к PostgreSQL через PDO |
| `ext-pgsql` | Нативный драйвер PostgreSQL |
| `ext-zip` | Работа с ZIP-архивами |
| `ext-gd` | Обработка изображений |
| `ext-pcntl` | Управление процессами (сигналы, форки) |
| `ext-sockets` | Низкоуровневая работа с сокетами |
| `ext-redis` | Клиент Redis (PECL) |
| `ext-amqp` | Клиент AMQP / RabbitMQ (PECL) |

## Внешние сервисы

| Сервис | Назначение |
|--------|------------|
| **PostgreSQL** | Основная реляционная база данных |
| **Redis** | Кэш (query cache, result cache Doctrine в production) |
| **RabbitMQ** | Брокер сообщений для асинхронной обработки событий |
| **SMTP** | Отправка email через `symfony/mailer` |

## Пакеты Composer

### Production

| Пакет | Описание |
|-------|----------|
| `doctrine/orm` | ORM для работы с базой данных через объектную модель. |
| `doctrine/doctrine-bundle` | Интеграция Doctrine ORM с Symfony (конфигурация, сервисы). |
| `doctrine/doctrine-migrations-bundle` | Интеграция системы миграций Doctrine с Symfony. |
| `doctrine/migrations` | Управление версиями схемы базы данных через миграции. |
| `nelmio/api-doc-bundle` | Автоматическая генерация OpenAPI-документации из аннотаций и атрибутов. |
| `symfony/framework-bundle` | Ядро Symfony: DI-контейнер, роутинг, конфигурация. |
| `symfony/security-bundle` | Аутентификация и авторизация пользователей. |
| `symfony/serializer` | Сериализация и десериализация объектов в JSON, XML и другие форматы. |
| `symfony/validator` | Валидация данных через атрибуты и ограничения. |
| `symfony/monolog-bundle` | Логирование через Monolog с поддержкой каналов и обработчиков. |
| `symfony/mailer` | Отправка email через различные транспорты (SMTP, DSN). |
| `symfony/console` | Инфраструктура для создания CLI-команд. |
| `symfony/dotenv` | Загрузка переменных окружения из `.env`-файлов. |
| `symfony/property-access` | Чтение и запись свойств объектов и элементов массивов по пути. |
| `symfony/property-info` | Извлечение метаданных о типах свойств объектов (используется сериализатором). |
| `symfony/asset` | Управление URL статических ресурсов с версионированием. |
| `symfony/twig-bundle` | Интеграция шаблонизатора Twig с Symfony. |
| `symfony/yaml` | Разбор и генерация YAML-файлов. |
| `symfony/runtime` | Управление жизненным циклом приложения и точкой входа. |
| `symfony/flex` | Менеджер рецептов Symfony для автоматической настройки пакетов. |
| `vich/uploader-bundle` | Загрузка и хранение файлов с привязкой к сущностям Doctrine. |

### Development

| `phpstan/extension-installer` | Автоматическая регистрация расширений PHPStan. |

| `symfony/web-profiler-bundle` | Веб-профайлер для отладки запросов, запросов к БД, событий. |
| `symfony/debug-bundle` | Дополнительные инструменты отладки (VarDumper интеграция). |
| `symfony/stopwatch` | Замер времени выполнения участков кода (используется профайлером). |
| `symfony/browser-kit` | Эмуляция HTTP-клиента для функциональных тестов контроллеров. |
| `symfony/css-selector` | CSS-селекторы для парсинга HTML в функциональных тестах. |
| `symplify/config-transformer` | Конвертация конфигурации Symfony из YAML/XML в PHP-формат. |
