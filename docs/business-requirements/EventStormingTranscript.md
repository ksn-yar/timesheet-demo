## Timesheet System Event Storming — расшифровка и группировка по доменам

На схеме видны следующие **цветовые обозначения** (легенда внизу):

- 🟡 **Команды** (жёлтые) — действия пользователя
- 🟠 **События** (оранжевые) — Domain Events
- 🟢 **Read Model / View** (зелёные) — списки, проекции
- 🔵 **Агрегаты** (голубые) — сущности
- 🩷 **Внешние системы / политики** (розовые)
- **CR** (отдельный цвет) — Change Request

---

## Домен 1: Client & Project Management

| Команда         | Событие        | Агрегат             |
|-----------------|----------------|---------------------|
| Создать клиента | Клиент создан  | Клиент              |
| Создать проект  | Проект создан  | Проект              |
| Создать CR      | CR создан      | CR (Change Request) |
| Создать задачу  | Задача создана | Задача              |

**Read Models:** Список клиентов, Список проектов, Список задач

---

## Домен 2: Work Configuration (Ставки, Роли, Работы)

| Команда        | Событие        | Агрегат |
|----------------|----------------|---------|
| Создать ставку | Ставка создана | Ставка  |
| Создать роль   | Роль создана   | Роль    |
| Создать работу | Работа создана | Работа  |

**Read Models:** Список работ

> Этот домен — справочники/конфигурация для тарификации

---

## Домен 3: User & Group Management

| Команда              | Событие             | Агрегат      |
|----------------------|---------------------|--------------|
| Создать группу       | Группа создана      | Группа       |
| Создать пользователя | Пользователь создан | Пользователь |

**Read Models:** Список пользователей

---

## Домен 4: Timesheet / Ticket Management (ядро системы)

| Команда                                            | Событие          | Агрегат |
|----------------------------------------------------|------------------|---------|
| Добавить тикеты вручную                            | Тикеты добавлены | Тикет   |
| Импортировать тикеты по правилам (внешняя система) | —                | —       |

**Внешняя система / политика:** Импортировать тикеты по правилам добавления вручную (розовый стикер — Policy или External System)

**Read Models:** Список тикетов

---

## Домен 5: Reporting

| Команда          | Событие          | Агрегат |
|------------------|------------------|---------|
| Добавить отчёт   | Отчёт добавлен   | Отчёт   |
| Выгрузить отчёты | Отчёты выгружены | —       |

**Read Models:** Список отчётов, Выгрузка отчётов

---

## Итоговая карта доменов

```
┌──────────────────────────────────────────────────────────────┐
│                      TIMESHEET SYSTEM                        │
│                                                              │
│  [Client & Project]  ─────────                               │
│  (клиенты, проекты,          │                               │
│   CR, задачи)                ▼                               │
│                       [Timesheet/Tickets]  ──►  [Reporting]  │
│  [Work Config]   ──►  (ядро системы)                         │
│  (ставки/роли/работы)        ▲                               │
│                              │                               │
│                   [User & Group Management]                  │
└──────────────────────────────────────────────────────────────┘
```

---

## Возможные Bounded Contexts

1. **ProjectContext** — клиенты, проекты, CR, задачи
2. **CatalogContext** — ставки, роли, работы (справочники)
3. **IdentityContext** — пользователи, группы
4. **TimesheetContext** — тикеты (ядро)
5. **ReportingContext** — отчёты, выгрузки
