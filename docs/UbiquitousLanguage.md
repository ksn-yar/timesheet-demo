# Ubiquitous Language — Timesheet System

> Единый глоссарий терминов для всех участников разработки.  
> Все термины используются **без перевода и синонимов** в коде, документации и коммуникациях.

---

## Bounded Context: Project Management

| Термин                  | Определение                                                          | Примечания                                                    |
|-------------------------|----------------------------------------------------------------------|---------------------------------------------------------------|
| **Client** (Клиент)     | Организация или физическое лицо, для которого выполняются работы     | Верхнеуровневый агрегат иерархии                              |
| **Project** (Проект)    | Совокупность работ, выполняемых для Client в рамках договора         | Принадлежит одному Client                                     |
| **CR** (Change Request) | Запрос на изменение, расширяющий или корректирующий скоуп Project    | Не является отдельным Project; привязан к конкретному Project |
| **Client List**         | Read Model: отфильтрованный список всех Client с базовыми атрибутами | Используется в выпадающих списках и таблицах                  |
| **Project List**        | Read Model: список Project в рамках конкретного Client               | Может быть отфильтрован по статусу                            |
| **Task** (Задача)       | Единица работы внутри Project или CR, к которой привязываются Ticket | Имеет название, описание, Project/CR, и опциональный эстимейт |
| **Task List**           | Read Model: список Task с фильтрацией по Project/CR                  |                                                               |

## Bounded Context: Work Catalog

> Справочный контекст. Сущности изменяются редко и используются другими контекстами как **read-only**.

| Термин            | Определение                                                                     | Примечания                                    |
|-------------------|---------------------------------------------------------------------------------|-----------------------------------------------|
| **Rate** (Ставка) | Тарифная ставка в единицу времени, применяемая к Role или Work                  | Имеет валюту, сумму и дату вступления в силу  |
| **Role** (Роль)   | Функциональная роль исполнителя (например, Developer, QA, PM)                   | Влияет на Rate при расчёте стоимости          |
| **Work** (Работа) | Классификатор вида выполняемой деятельности (например, Development, Consulting) | Используется для группировки Ticket в отчётах |
| **Work List**     | Read Model: полный список доступных Work                                        |                                               |

## Bounded Context: Identity

| Термин                    | Определение                                                       | Примечания                                                   |
|---------------------------|-------------------------------------------------------------------|--------------------------------------------------------------|
| **User** (Пользователь)   | Физическое лицо, имеющее доступ к системе                         | Обладает Role в рамках Group или глобально                   |
| **Group** (Группа)        | Организационная единица, объединяющая User                        | Используется для разграничения доступа и группировки отчётов |
| **Admin** (Администратор) | Тип User с правами на управление справочниками и конфигурацией    | Не является отдельным агрегатом — это роль User              |
| **Employee** (Сотрудник)  | Тип User, который вносит трудозатраты через Ticket                | Контекстная роль User в Timesheet Context                    |
| **User List**             | Read Model: список User с возможностью фильтрации по Group и Role |                                                              |

## Bounded Context: Timesheet *(ядро домена)*

| Термин              | Определение                                                                     | Примечания                                                                     |
|---------------------|---------------------------------------------------------------------------------|--------------------------------------------------------------------------------|
| **Ticket** (Тикет)  | Запись о затраченном времени Employee на конкретную Task                        | Основная сущность системы. Содержит: дату, количество часов, Work, комментарий |
| **Manual Ticket**   | Ticket, добавленный вручную через форму Employee                                | В отличие от импортированного                                                  |
| **Imported Ticket** | Ticket, созданный автоматически по правилам из внешней системы                  | Источник и правила импорта задаются через политику импорта                     |
| **Import Policy**   | Набор правил, по которым внешние данные трансформируются в Ticket               | Живёт на границе с внешней системой (Anti-Corruption Layer)                    |
| **Ticket List**     | Read Model: список Ticket с фильтрацией по Employee, Project, CR, Task, периоду |                                                                                |
| **Add Tickets**     | Команда: добавить один или несколько Ticket вручную                             | Исполнитель — Employee                                                         |
| **Import Tickets**  | Команда: запустить импорт Ticket по Import Policy                               | Исполнитель — System или Admin                                                 |

## Bounded Context: Reporting

| Термин                              | Определение                                                          | Примечания                                                   |
|-------------------------------------|----------------------------------------------------------------------|--------------------------------------------------------------|
| **Report** (Отчёт)                  | Агрегированное представление Ticket за период по заданным параметрам | Может быть сгруппирован по Employee, Project, CR, Work, Task |
| **Report Export** (Выгрузка отчёта) | Файл (CSV, XLSX, PDF) сформированный из Report                       | Является результирующим артефактом — не агрегатом            |
| **Add Report**                      | Команда: сформировать Report по заданным фильтрам                    |                                                              |
| **Export Reports**                  | Команда: выгрузить один или несколько Report в файл                  |                                                              |
| **Report List**                     | Read Model: список сохранённых Report с мета-информацией             |                                                              |
| **Exported Reports List**           | Read Model: список доступных файлов выгрузок                         |                                                              |

## Роли (Actors)

| Роль         | Описание                          | Основные действия                                                            |
|--------------|-----------------------------------|------------------------------------------------------------------------------|
| **Admin**    | Управляет конфигурацией системы   | Создаёт Client, Project, CR, Rate, Role, Work, Group, User; запускает импорт |
| **Employee** | Вносит трудозатраты               | Добавляет Ticket вручную; просматривает свои Ticket                          |
| **Manager**  | Контролирует и анализирует работы | Просматривает Report; формирует выгрузки                                     |

---

## Ключевые бизнес-правила

> Инварианты, которые **никогда не нарушаются** вне зависимости от контекста.

- Ticket **всегда** привязан к Task; Task **всегда** привязана к Project или CR.
- CR **всегда** принадлежит Project; Project **всегда** принадлежит Client.
- Rate применяется к Ticket на момент его создания (не изменяется ретроспективно).
- Employee может добавлять Ticket только за себя, если не наделён правами Admin.
- Imported Ticket нельзя редактировать вручную без явного разрешения Import Policy.

## Антипаттерны наименований

> Термины, которые **запрещены** в коде и документации во избежание неоднозначности.

| ❌ Запрещено            | ✅ Использовать                             |
|------------------------|--------------------------------------------|
| `TimeEntry`            | `Ticket`                                   |
| `ChangeRequest`        | `CR`                                       |
| `Worker` / `Staff`     | `Employee`                                 |
| `HourlyRate`           | `Rate`                                     |
| `JobType`              | `Work`                                     |
| `Export` (как агрегат) | `ReportExport` (как Value Object/артефакт) |
| `Log`                  | `Ticket`                                   |
